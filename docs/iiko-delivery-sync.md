# Доставка Bulka в iikoFront 9.4

Оплаченный заказ доставки создаётся в iikoCloud как стандартный
`DeliveryByCourier`. Поэтому кассир видит в iikoFront номер заказа Bulka, клиента,
телефон, адрес, состав, оплату и обязательное требование автомобильного курьера.

## Совместимость

- iikoFront 9.4 использует API `V9Preview7`.
- Плагин Bulka собирается с `Resto.Front.Api.V9Preview7` 9.4.7024-alpha.
- Стабильный `V9` предназначен для iikoFront 9.5 и с кассой 9.4 несовместим.

## Обязательная настройка iikoOffice

1. Создайте тип оплаты для оплаченных онлайн-заказов с видом `External`.
2. Получите его UUID через `/api/1/payment_types` и задайте
   `IIKO_PAYMENT_TYPE_ID`.
3. Получите группу терминалов через `/api/1/terminal_groups` и задайте
   `IIKO_TERMINAL_GROUP_ID` либо соответствие филиалов в
   `IIKO_TERMINAL_GROUPS_JSON`.
4. Для `IIKO_ADDRESS_FORMAT=city` включите в настройках предприятия новый формат
   адреса доставки с полем «Куда везти». Если организация использует старый
   справочник улиц, задайте `IIKO_ADDRESS_FORMAT=legacy`.
5. Включите единственный экземпляр фоновых обработчиков:

   ```dotenv
   IIKO_ORDER_EXPORT_ENABLED=true
   IIKO_TERMINAL_GROUP_ID=<uuid>
   IIKO_PAYMENT_TYPE_ID=<uuid external payment>
   IIKO_ADDRESS_FORMAT=city
   RUN_BACKGROUND_WORKERS=true
   ```

Для отдельного аккаунта Астаны используются
`IIKO_ASTANA_TERMINAL_GROUP_ID`, `IIKO_ASTANA_TERMINAL_GROUPS_JSON`,
`IIKO_ASTANA_PAYMENT_TYPE_ID` и `IIKO_ASTANA_ADDRESS_FORMAT`.

## Рабочий процесс

1. После подтверждения оплаты сервер ставит доставку в долговечную очередь iiko.
2. В iiko создаётся один заказ с постоянным UUID. Повтор после таймаута безопасен:
   сервер сначала проверит заказ по этому UUID и не создаст дубликат.
3. Статусы iiko опрашиваются каждые 30 секунд.
4. `WaitCooking` или `ReadyForCooking` означает, что кассир принял заказ, и
   запускает вызов курьера. `CookingStarted` также используется как безопасный
   резервный сигнал, если промежуточный статус был пропущен между опросами.
5. `CookingCompleted` и последующие статусы переводят локальный экран кухни в
   «Готово».
6. Ошибки отправки и вызова курьера повторяются с увеличивающейся задержкой и
   записываются в заказ для диагностики.

Перед боевым включением обязателен один тестовый заказ с реальной внешней оплатой,
адресом, скидкой и доставкой. Проверьте его одновременно в iikoFront,
«Диспетчерской» Bulka и кабинете Яндекс Доставки.
