# Публикация без CI

С 7 сентября 2026 по просьбе владельца GitHub workflow `CI` отключён. Автоматические триггеры push/PR удалены, текущий запуск отменён. Мониторинг доступности рабочего сайта не относится к CI и сохранён.

Обычная публикация: `./scripts/deploy-vps.ps1` из чистой копии ветки `main`, совпадающей с `origin/main`. Скрипт устанавливает зависимости из lock-файлов и локально собирает Flutter web и админку. Android APK/AAB не собираются. GitHub Actions и токен GitHub для публикации не требуются.

Перед обновлением остаются резервная копия БД, обязательные миграции, промежуточный запуск, проверка готовности сайта и сверка опубликованного Flutter-файла. При ошибке запуска восстанавливается предыдущий выпуск. Локальный выпуск отмечен в manifest как `local-build`, без утверждения об успешном CI.

`-SkipBuild` для обычной локальной публикации запрещён, чтобы не отправить устаревшие файлы. Старый режим `-UseCiArtifact` оставлен только для явного использования после повторного включения CI.

Проверки кода можно запускать вручную перед изменениями. Успех CI больше не является условием публикации. Эта инструкция заменяет прежнее требование ждать GitHub CI для обычного выпуска.
