# Продажи выбранного товара iiko

В админ-панели откройте **iiko Dashboard → Продажи товара**. В верхней строке выберите город и точку либо «Все точки». Нажмите на период, задайте даты, затем найдите товар по названию. Поиск получает товары из iiko и выбирает товар по его ID, поэтому одинаковые или изменённые названия не смешивают продажи разных товаров. Поиск «көже» также находит позицию «Коже».

Кнопка **Показать продажи** показывает количество и выручку за период, ниже — продажи по дням и, при выборе всех точек, по точкам города. Дни или точки без продаж сохраняются с нулём. Нажмите **Скачать Excel** и выберите формат: **Отчёт по дням** суммирует все выбранные точки по каждой дате, а **Общий отчёт по точкам** суммирует период отдельно для каждой точки. Оба файла содержат итоги; при выборе одной точки выгрузка ограничена ею. Период ограничен 367 календарными днями.

Источник — iiko OLAP SALES выбранного сервера. Отчёт использует дату открытия чека `OpenDate.Typed`, количество `DishAmountInt`, выручку после скидок `DishDiscountSumInt` и сумму до скидок `DishSumInt`. Удалённые строки исключены. «Все точки» выбирает розничные подразделения города из справочника выбранного сервера; другой город, доставка, центральный офис и цех в результат не входят. Запросы Chain и RMS не складываются друг с другом.

Доступ к поиску, отчёту и Excel ограничен владельцем и администратором. Логин, пароль и ключ сессии iiko не передаются в браузер или файл. История результатов хранится только в ограниченном по времени кэше сервера.
