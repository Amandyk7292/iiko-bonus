# Исправления повторного аудита

- Ручные цена, название и фотография сбрасываются явным null. Кнопка «Использовать цену iiko» заполняет исходную цену; сохранение удаляет ручное переопределение. Проверены повторное чтение и последующее изменение исходной цены. Кассовая цена не изменяется.
- Главная и каталог не выполняют периодические сетевые обновления в скрытых вкладках. Главная использует один таймер и обновляется при возвращении. События сохраняют необходимость последующего обновления.
- Убрана предварительная загрузка всех аватаров при запуске. Firebase SDK загружается после первого кадра (с резервным тайм-аутом), не конкурируя с загрузкой renderer.
- Основной JavaScript предварительно сжимается при сборке: Brotli 11 и Gzip 9. Brotli-представление уменьшено примерно с 1,71 до 1,28 MB без изменения исходных байтов после распаковки. Отдельно проверены согласование кодирования, HEAD, ETag/304 и Range.
- Исправлены тестовые DOM/API fixtures и зависимость health-теста от скорости машины. Тесты переноса категорий используют явный изолированный database stub.
- В версионной конфигурации добавлены 12 проверенных сопоставлений пекарен Актау с Department.Id iiko. Для филиала без кассовой истории остаётся онлайн-подстановка.

Проверки: Flutter 427/427; admin 324/324; backend 1103 успешно, 5 пропущено, 0 ошибок. Дополнительные 11 тестов рекомендаций прошли после уточнения привязки 19А/11. Flutter analyze и backend lint без замечаний; сборка admin и Flutter web успешна. Браузерная проверка выполнялась с подставным API, реальные цены не менялись.
