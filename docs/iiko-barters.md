# Бартеры в iiko Dashboard

Вкладка использует выбранные город, подразделение и период. Показывает выдачи, товары,
количество, стоимость по накладной, историю по блогерам и экспорт Excel.

Источник — проведённые расходные накладные контрагентов с точным названием «Бартер»,
«Блогер» или «Блогеры» (без учёта регистра). Список контрагентов читается из `suppliers`.
Накладные загружаются из `documents/export/outgoingInvoice` с параметрами `from`, `to`
и **`supplierId`**. Этот фильтр проверен на действующем iiko; `counteragentId` игнорируется.
Эти старые API возвращают пустые объекты при запросе JSON, поэтому используется XML.
DTD запрещены; размер ответа и таймаут ограничены клиентом.

Сумма берётся из `items.item.sum`, количество — из `amount`. Текущая цена товара,
себестоимость, зеркальные проводки и баланс взаиморасчётов не подменяют сумму накладной.
Учитываются только `PROCESSED` и только выбранные контрагенты/даты. Идентификатор
накладной предотвращает дубли; номера с ведущими нулями остаются строками.
При выборе подразделения учитываются его строки накладной. Chain и RMS не суммируются.

В проверенных накладных имя блогера отсутствует: комментарий содержит только кассовые
данные. Имя или ник вводится в карточке выдачи и сохраняется в `iiko_barter_people`.
Ключ — хеш города и UUID накладной, поэтому привязка переживает смену периода и
переключение Chain/RMS. Имя объединяет историю; незаполненные выдачи видны отдельно.
Доступ к чтению, записи имён и экспорту имеют только owner/admin. В iiko ничего не пишется.
Изменения имён применяются к отчёту и экспорту сразу, без ожидания обновления кэша накладных.

Перед запуском нужна миграция `20260908190000_iiko_barter_people.sql`.
Таблица закрыта RLS от anon/authenticated и доступна серверному service_role.

Проверка 08.09.2026: Актау, 01–08.09 — 27 накладных, 321 685,10 ₸;
Астана, 01.08–08.09 — 4 накладных, 38 732 ₸. Имена отсутствуют во всех этих документах.
В сводном OLAP отсутствовали две накладные Актау, поэтому вкладка читает документы напрямую.
Автотесты покрывают фильтры, точные суммы, дробное количество, пустые значения, имена,
права, сохранение и Excel. Интерфейс проверен на ширинах 320, 390, 768 и 1280 px.
