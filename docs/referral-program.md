# Приглашения друзей

В приложении: «Профиль» → «Пригласите друга» → «Пригласить по ссылке». Ссылка открывает каталог приложения или веб-каталог. Код сохраняется на устройстве до регистрации и автоматически заполняет поле приглашения; его можно удалить или исправить. Если приложение ещё не установлено, друг может зарегистрироваться в браузере по ссылке, затем войти в приложение тем же номером. Передача кода из браузера через установку из магазина не гарантируется.

При регистрации сервер связывает подтверждённый номер друга с пригласившим клиентом. Самоприглашения, смена уже принятого кода и приглашения после первой покупки запрещены. Ручной ввод кода до первой покупки остаётся доступным.

После первой оплаченной покупки начисляются 1 000 ₸ бонусами пригласившему и 500 ₸ другу. Учитываются онлайн-платежи и подтверждённые кассовые покупки с привязанной картой клиента. Покупка без идентификации клиента не может быть связана с приглашением.

В админке: «Правила бонусов» → «Приглашение друзей». Настраиваются обе суммы, минимальная первая покупка и приём новых приглашений. Условия фиксируются при принятии кода; изменение настроек не меняет уже принятые приглашения. Если первая покупка ниже установленного минимума, последующие покупки не дают реферальную награду.

Событие покупки сохраняется в транзакции оплаты. Серверный обработчик выполняется каждые 15 секунд и начисляет обе награды в одной транзакции. Повторная доставка, перезапуск и повторная покупка не создают повторных начислений. Возврат до обработки отменяет награду; возврат после начисления не отзывает реферальные бонусы автоматически.

Начисления и связь приглашения сохраняются в `referral_redemptions`, кошельки — в `customers` и `transactions`. Таблица `referral_first_purchases` доступна только серверу, удаляется каскадно вместе с клиентом и включена в экспорт персональных данных.
