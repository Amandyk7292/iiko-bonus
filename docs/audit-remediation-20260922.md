# Исправления аудита от 22 сентября 2026

- Подтверждённый отказ банка завершает попытку пополнения. Запоздалый отказ не
  перезаписывает зачисление; поздний подтверждённый успех по-прежнему сверяется
  с банком и зачисляется однократно.
- Конфигурация товара, группы и варианты сохраняются одной транзакцией
  `replace_product_options`. Ошибка откатывает весь набор. Неизменённые коды
  групп и вариантов сохраняют UUID, используемые существующими корзинами.
- Срок изготовления проверяется по времени получения заказа. Календарь
  получает список товаров, начинает окно выбора с допустимого дня и учитывает
  индивидуальные ограничения. Итоговое время включается в расшифровку для кассы.
- При недоступности настроек уведомлений отправка откладывается. Отсутствие
  ответа базы не считается согласием клиента на рассылку.
- Очередь push записывает начало попытки до обращения к FCM. Потерянный ответ
  или перезапуск после отправки оставляет неопределённый результат, который
  не пересылается автоматически. Однозначный отказ провайдера допускает повтор.
  Такая политика исключает слепые повторы, но может пропустить сообщение,
  фактический результат которого нельзя установить.
- Размеры текста редактора этикеток приведены к физическим пунктам. Windows
  показывает тот же PDF, который печатает. Текст подбирается по размеру поля;
  состав не обрезается молча. Если текст невозможно разместить, печать
  останавливается до передачи задания принтеру. Бумага остаётся из шаблона.
- Стили контактов загружаются со страницей контактов. Общий CSS уменьшен до
  32 359 байт gzip при прежнем лимите 33 000; бюджет не повышался.

Миграции `20260922160000_atomic_product_options.sql` и
`20260922161000_push_uncertain_delivery.sql` применяются перед новым backend.
Публичных разрешений для изменения настроек или очереди не добавлено.

Проверено: полный `npm run verify`, 467 Flutter-тестов, реальные транзакции SQL
в изолированном PGlite, статический анализ Flutter, генерация и визуальная
проверка PDF 58×40 мм с казахским и русским составом. Физические платежи,
уведомления клиентам и печать на Xprinter для тестирования не выполнялись.

Нативное приложение получает обновление через Shorebird для iOS 1.0.8+43.
Windows-программа печати обновлена до 1.0.4+5; её сборка выполняется отдельным
ручным workflow Windows label printer build. Автоматический CI на push не включён.
