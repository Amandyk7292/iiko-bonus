# Проверка разделов Bulka — 7 сентября 2026

В Chrome под текущим владельцем открыты все 27 исходных разделов рабочего сайта. Проверена загрузка интерфейса и данных. Это не означает проверку каждой кнопки и каждой роли на реальных операциях.

По просьбе владельца остаются 25 разделов: «Диспетчерская» и «Курьеры» удалены из навигации. Их старые URL перенаправляют в разрешённый раздел. Яндекс управляется из карточки оплаченного заказа; внутренние назначения курьеров убраны. Курьерский аккаунт не получает расширенных прав.

Причина единичных сетевых таймаутов настроек/поддержки не установлена. Серверная обработка поддержки при повторной проверке занимала 404–819 мс. Дополнительно устранены два воспроизводимых недостатка: таймаут прекращался до полного чтения JSON и каждая вкладка держала отдельный SSE при HTTP/1.1. Теперь поддерживаемые браузеры разделяют соединение между вкладками одной учётной записи и области данных.

## Автоматические проверки

- TypeScript, сборка админки, ограничения размеров сборки и исходников — успешно.
- Полный Vitest: **249/249**. В том числе роли/редиректы, поиск, ошибки/Retry, бонусные знаки, CSV, Яндекс и совместное соединение вкладок.
- Полный Playwright: **81/81**, Chromium 390×844, 768×1024, 1440×900. API подменены тестовыми ответами. Проверены в том числе мобильный состав заказа и доступность его колонок через прокрутку.
- Flutter analyze — без замечаний; 68 целевых widget-тестов прошли, последние правки каталога дополнительно проверены 10 тестами.
- APK/AAB не собирались. Проверки Flutter web выполняются при публикации.

Команды: `npm --prefix admin-ui run test -- --run`; из `admin-ui` — `node node_modules/@playwright/test/cli.js test --reporter=line --workers=4`.

## Границы проверки

Автотесты не заменяют реальный проход оплаты → кухня → поездка курьера → вручение → возврат. В этом аудите не менялись балансы, заказы и права, не выполнялись рассылки и реальные вызовы курьера. Вход кассира на физическом устройстве и Safari/iOS WebView не проверялись. Полная доступность всех рабочих форм через скринридер также не подтверждена.

Оставшиеся проблемы и исправления перечислены в соседнем отчёте `2026-09-07-ui-ux-audit.md`.
