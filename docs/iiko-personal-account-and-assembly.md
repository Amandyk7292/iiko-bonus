# Bulka iikoFront 1.9.0

## Установка

На каждой кассе нужен плагин 1.9.0 для iikoFront 9.4 / API V9Preview7.
Закройте iikoFront перед заменой DLL и Manifest.xml. При обновлении сохраните свой .dll.config и папку данных Bulka: там находятся привязка кассы и незавершённые операции. Для новой установки используйте полный комплект и привязку кассы из приложения продавца.

## Оплата личным счётом

В iikoOffice создайте внешний безналичный тип оплаты «Bulka личный счёт», выберите обработчик с таким же названием. Не включайте проведение как скидку. Настройте доступность типа оплаты на нужной кассе.

1. Добавьте товары в чек и выберите «Bulka личный счёт» на всю сумму.
2. Отсканируйте QR клиента.
3. Клиент получает сумму, точку и шестизначный код в push и центре уведомлений приложения. Он сообщает код кассиру.
4. Кассир вводит код. Код действует 5 минут; после 5 неверных попыток требуется новый запрос.
5. При проведении оплаты списывается вся сумма. Сам ввод кода деньги не списывает.

Нужна связь кассы с сервером. При неизвестном результате повторяйте исходную операцию: одинаковая транзакция не списывает деньги повторно. Нельзя смешивать оплату личным счётом с другой оплатой. При изменении чека удалите неподтверждённую оплату и запросите новый код. Возврат выполняется по исходному чеку полностью; повторный возврат не увеличивает баланс ещё раз. Возврат без исходного чека и частичный возврат личного счёта не поддерживаются.

При выключенном push клиент может прочитать код в центре уведомлений. Существующее приложение поддерживает этот формат, новая IPA не требуется.

## Сборочный чек

После принятия оплаченного заказа на планшете или кассе (`preparing`) сервер ставит отдельный сборочный чек в очередь. Подключённый плагин проверяет очередь каждые 5 секунд. Сверху печатается номер заказа iikoFront, ниже номер Bulka, товары и выбранные варианты. Это нефискальный документ. Фискальная печать остаётся при выдаче/завершении заказа.

В iikoOffice настройте принтер пречеков либо документов для зала кассы. Одна касса закрепляет за собой задание; вторая не печатает его повторно. Если касса отключена, задание ждёт подключения. Если после начала печати произошёл сбой, автоматическая повторная печать останавливается: проверьте ленту, откройте связанный заказ и нажмите «Сборочный чек Bulka», затем подтвердите повтор.

Проверка на настоящем принтере необходима после установки; программные проверки не подтверждают физический выход бумаги.

## День рождения

Админка → Маркетинг → Автоматические рассылки → День рождения → Текст.
В редакторе доступны три языка и поле «Подарок в бонусах» (0–100000).
0 означает только поздравление. Начисляются бонусы лояльности, а не деньги личного счёта.
Подарок и поздравление фиксируются один раз за календарный год по часовому поясу Актау. Изменение даты рождения или пересоздание рассылки не разрешает повтор. Смена суммы влияет только на будущие поздравления. Рассылка учитывает согласие клиента и тихие часы. Уже поздравлённым клиентам подарок задним числом не начисляется.

## Проверки выпуска

SQL-тесты: подтверждение без списания; неверный код, срок, филиал и изменённая сумма; идемпотентные оплата и возврат; однократный подарок; отделение сборочной и фискальной очереди; конкуренция двух касс. Приложение покупателя использует уже существующий центр уведомлений.
