# Яндекс.Доставка для Bulka

Интеграция вызывает курьера из раздела «Диспетчерская» в админ-панели. Внутренние
курьеры Bulka и заявки Яндекс.Доставки хранятся раздельно.

## Включение

1. Получите API-токен Яндекс Доставки для бизнеса.
2. Примените миграции:

   ```powershell
   npm run db:migrate
   ```

3. Добавьте в переменные окружения VPS:

   ```dotenv
   YANDEX_DELIVERY_ENABLED=true
   YANDEX_DELIVERY_AUTO_DISPATCH=true
   YANDEX_DELIVERY_API_TOKEN=<секретный токен>
   YANDEX_DELIVERY_SENDER_PHONE=+77000000000
   YANDEX_DELIVERY_CARGO_OPTIONS=auto_courier,thermobag
   RUN_YANDEX_DELIVERY_WORKER=true
   RUN_BACKGROUND_WORKERS=true
   ```

4. Перезапустите сервер. Статус настройки отображается в «Диспетчерской».

Полный список необязательных параметров и безопасные значения по умолчанию находятся
в `.env.example`.

## Рабочий процесс

1. Клиент оплачивает заказ с типом «Доставка» и выбирает точку на карте. На этом шаге
   курьер ещё не вызывается.
2. Кассир видит оплаченный заказ на планшете и вручную пробивает его в iikoFront.
   Кухня принимает заказ кнопкой «Принять» на планшете. Только после этого сервер
   создаёт одну идемпотентную заявку Яндекса и автоматически подтверждает её после
   расчёта. Повторная обработка продолжит ту же заявку и не вызовет второго курьера.
3. Если автоматический вызов выключен, оператор может рассчитать стоимость и вызвать
   Яндекс вручную из «Диспетчерской».
4. Курьер получает название и адрес точки Bulka, номер и состав заказа, адрес клиента,
   подъезд, этаж, квартиру и комментарий клиента.
5. Сервер обновляет статус каждые 15 секунд, показывает кассиру имя, тип транспорта,
   модель, цвет и номер автомобиля, а клиенту — ссылку отслеживания.
6. Передать заказ нельзя, пока Яндекс не вернул данные автомобильного курьера.
7. После фактической доставки заказ автоматически завершается.

Повторное нажатие не создаёт второго курьера: для повторных запросов используется тот
же `request_id`. Платная отмена требует отдельного подтверждения в интерфейсе.

## Важные ограничения

- Заявка доступна только для оплаченного заказа с координатами филиала и клиента.
- Сервер всегда добавляет требования `auto_courier` и `thermobag`, а также запрещает
  робота. Удалить эти требования через переменные окружения нельзя.
- Пеший, вело- или мотокурьер отображается как ошибка; кнопка передачи заказа будет
  заблокирована.
- Создавать и отменять заявку могут `admin`, `owner`, `branch_manager` и `operator`.
- Цена Яндекса сейчас является расходом Bulka и не меняет уже оплаченную клиентом
  стоимость доставки.
- Токен хранится только на сервере; его нельзя добавлять во Flutter или admin bundle.
- Перед боевым включением выполните один тестовый заказ на короткий маршрут.
