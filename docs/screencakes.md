# Экран продаж блинов

Публичная страница `/screencakes` показывает только проданный вес товара
`Блины - 17` (`481f6762-b42b-46c8-8fe4-6d496b6c7079`) по Актау.
В iiko единица товара — кг. Пересчёт в штуки не выполняется без подтверждённого
веса одного блина. Выручка, серверы, документы и учётные данные не публикуются.

Используется один активный настроенный Aktau Chain; если его нет — активные
настроенные RMS Актау. Chain и его RMS не суммируются. Исключаются удалённые
заказы, удалённые позиции и сторнированные продажи. Периоды определяются по
часовому поясу Казахстана. «Весь период» — доступная история iiko с 2000 года;
не загруженные в iiko архивы не восстанавливаются и не оцениваются.

Страница проверяет данные раз в минуту, при расчёте — раз в пять секунд.
Запросы объединены на сервере. История запрашивается по годам, чтобы избежать
тайм-аута большого отчёта, и пересчитывается ежедневно. Текущий год и месяц
обновляются раз в минуту при открытом экране. Задержка синхронизации касс с iiko
остаётся зависимостью источника. Это периодическое обновление, не поток событий.

Снимок и исторические суммы сохраняются в системной временной папке
`bulka-screen-cakes/aktau-bliny17-v1.json`. После перезапуска сервис читает снимок
и обновляет его в фоне. При сбое отображаются последние данные с предупреждением;
при смене месяца старые итоги не выдаются за новый период. Для принудительного
пересчёта истории очистите этот файл и перезапустите процесс в окно обслуживания.

Проверено: точный товар и единица, отсутствие двойного учёта Chain/RMS, календарные
границы, кеш после перезапуска, отказ источника, смена месяца. Браузер: 1920×1080,
1366×768, 390×844 и 320×700; автоматическое восстановление после 503 без потери
последних показаний. Страница не загружает Flutter.
