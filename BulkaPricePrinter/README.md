# Bulka Price Printer

Windows-приложение для прямой печати этикеток 70 × 50 мм на XPrinter XP-365B.

- Загружает актуальные товары Актау и Астаны из `bulka.com.kz`.
- Ищет по названию и штрихкоду.
- Запоминает город и выбранный Windows-принтер.
- Печатает PDF-этикетку напрямую через очередь Windows без системного диалога.
- Поддерживает несколько копий и сроки годности в днях или часах.

Перед первым запуском установите официальный Windows-драйвер XP-365B и добавьте принтер в Windows. В приложении выберите его один раз.
