Плагин Bulka для iikoFront

Перед обновлением закройте iikoFront и сохраните текущий файл Resto.Front.Api.IikoBonusPlugin.dll.config.

Обновление установленной кассы

  1. Закройте iikoFront на кассе.
  2. Сделайте копию папки установленного плагина.
  3. Из архива замените DLL, Manifest.xml и файлы документации.
  4. Оставьте прежний файл .dll.config и локальную папку данных Bulka.
  5. Запустите iikoFront и откройте «Статус бонусов».
  6. В админке откройте «Кассы и интеграции» и убедитесь, что версия и принтер отмечены зелёным.

Новая касса

Установите полный архив, запустите iikoFront и выполните привязку шестизначным кодом из кабинета кассира. Для сборочного чека настройте принтер пречеков или документов для зала.

Если касса не появилась

Проверьте интернет, связь с главной кассой и журнал плагина. Старую версию можно временно разрешить в политике версий, но финансовые операции следует возобновлять только после проверки совместимости.
