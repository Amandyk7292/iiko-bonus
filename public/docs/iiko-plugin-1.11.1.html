Bulka для iikoFront 1.11.1

Выпуск сохраняет функции 1.11.0 и исправляет подготовку оплаты бонусами и сертификатами, повторы после ошибок связи и восстановление локальных журналов.

Сначала должен быть обновлён сервер Bulka. На действующей кассе сохраняются файл конфигурации, привязка и все журналы. Архив не устанавливает обновление автоматически.

Скачать

  • Обновление установленной кассы — DLL и Manifest без конфигурации. SHA256 архива.
  • Полный комплект для новой кассы — безопасный шаблон и инструкции. SHA256 архива.

Обновление действующей кассы

  1. Завершите текущую кассовую операцию и штатно закройте iikoFront.
  2. Сохраните копию действующей папки плагина и локальных данных кассы.
  3. Из update-архива замените только Resto.Front.Api.IikoBonusPlugin.dll и Manifest.xml в существующей папке плагина.
  4. Оставьте прежний .dll.config и папку данных %LOCALAPPDATA%\Bulka\IikoBonusPlugin либо настроенный IIKO_LOYALTY_DATA_DIR. Пустым шаблоном из полного комплекта рабочие настройки не заменяйте.
  5. Запустите iikoFront под прежним Windows-пользователем. Проверьте журнал загрузки и «Статус бонусов». В админке «Кассы и интеграции» должны появиться версия 1.11.1 и новое время связи.
  6. Повторите установку на каждой кассе филиала. Публикация архива не подтверждает обновление остальных касс.

Если остались ошибки очереди

Старые чеки с неизвестным результатом после сбоя требуют сверки с фактическими чеками iikoFront. Не удаляйте журнал и не создавайте второй чек ради снятия ошибки. Версия плагина и состояние старых инцидентов проверяются отдельно.

При повреждении журнала или отсутствии подтверждения резерва оплата может быть приостановлена. Сохраните файлы и проверьте связь и состояние журнала; не заменяйте их пустыми файлами.

Новая касса

Используйте полный комплект и инструкции PAIRING.md и PAYMENT_SETUP.md. Для каждой новой кассы нужен отдельный шестизначный код из приложения кассира. Привязка защищена Windows и идентификатором терминала; её нельзя копировать с другого устройства.

Совместимость: .NET Framework 4.7.2, iikoFront с API V9Preview7 и лицензионный модуль 21016318. DLL самого API предоставляет iikoFront.
